# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private vulnerability reporting:
open the **Security** tab of this repository and choose **Report a vulnerability**
(<https://github.com/slide-ng/slide.ng-themes/security/advisories/new>).

Describe what you found, which package and version it affects, and how to reproduce it. We will answer
in the report and keep it private until a fix is released.

If you cannot use GitHub, email erkamyaman35@gmail.com with "Security" in the subject.

## Scope

The packages here are themes: layouts, components and CSS that slide.ng builds into a deck. Problems
such as script injection through a layout, or a package that runs code at install time, are in scope.
Problems in slide.ng itself belong in the slide.ng repository.

## Supported versions

Only the latest release of each package gets fixes.
